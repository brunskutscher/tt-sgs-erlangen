# Homepage der SGS Tischtennis Abteilung


## Technologie Stack

Die seite bassiert auf dem [Hugo](https://gohugo.io/) Static Site Generator. Das Theme ist [Ananke](https://github.com/gohugo-ananke/ananke).

Die Inhalte werden in Markdown-Dateien im `content`-Verzeichnis gepflegt. Die Konfiguration erfolgt über die `hugo.toml` Datei.

Vom Theme-Ananke werden Layouts, Stile und Skripte bereitgestellt, die das Erscheinungsbild der Website bestimmen. Adaptierungen können durch eigene Layouts, Stile und Skripte vorgenommen werden.



## Installation

1. Hugo installieren: [https://gohugo.io/getting-started/installing/](https://gohugo.io/getting-started/installing/)
2. Repository klonen: `git clone https://github.com/dein-benutzername/tt-sgs-erlangen.git`
3. In das Projektverzeichnis wechseln: `cd tt-sgs-erlangen`
4. Submodule initialisieren: `git submodule update --init --recursive`
5. Lokalen Server starten: `hugo server -D`

Danach kann die Website im Browser unter `http://localhost:1313` aufgerufen werden.
